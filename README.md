# ✦ Lyra's Portfolio & Engineering Journal

A minimal, editor-inspired personal portfolio and engineering journal built with HTML5, CSS3, JavaScript, and live GitHub API synchronization.

## ✨ Key Features
- **Editor File-Tree Layout**: Interactive sidebar navigation mimicking modern code editors.
- **Live GitHub Profile Sync**: Real-time codebase language distribution and annual contribution heatmap for [`@Lyra-4leafclover`](https://github.com/Lyra-4leafclover).
- **Light & Dark Mode**: Low-contrast, easy-on-the-eyes slate charcoal dark mode with top-right toggle pill.
- **Engineering Journal & Blog**: Full-screen article reader modal and searchable blog archive.
- **Realtime Cloud Guestbook**: Multi-provider login (GitHub, Gmail, Discord, Email/Password) with real-time comment synchronization.

## 🚀 Deployment
This repository is pre-configured for instant deployment on **Vercel** or **GitHub Pages**.

### Vercel Deployment:
1. Import this repository into your Vercel Dashboard.
2. Click **Deploy**. No custom build step required.
